# 操作员 Operator

## 版本与来源

核验于 2026-08-25，基于 Alloyed Collective + Patch 1.4.1。官方设计/默认技能：https://steamcommunity.com/ogg/632360/announcements/detail/524227425953907077 ；官方发售与无人机全局更新：https://steamcommunity.com/ogg/632360/announcements/detail/534364965583192573 ；1.4.1：https://steamcommunity.com/ogg/632360/announcements/detail/497214077375874960 ；当前技能/无人机：https://riskofrain2.wiki.gg/wiki/Operator ；命令细节：https://riskofrain2.wiki.gg/wiki/ADMIN-OVERRIDE 。推荐为编辑判断。

## 角色定位

依靠无人机数量、种类和升级质量放大技能库存的前线指挥手。被动 `Drone Tech` 每关带两台自选 Mk 2 无人机；它们倒地会自动修复、不能废弃，并会进入 Hidden Realms。购买新无人机既增加战力，也给二技能增加一层命令充能，因此金币路线本身就是伤害成长。

## 当前技能与推荐配置

| 槽位 | 选择与解锁 | 推荐 |
|---|---|---|
| 被动无人机 | `Gunner Drone Mk 2`、`Healing Drone Mk 2`（默认）；`Transport Drone Mk 2`（挑战解锁） | 单人 **Gunner + Healing** 最稳；熟悉后 Transport 提箱子搬运/机动 |
| 主技能 | `H3-11 OCR Custom`（默认、唯一） | 150%–600% 充能弹，击杀跳弹；固定 |
| 副技能 | `ADMIN-OVERRIDE`（默认）；`CMD-SWARM`（挑战解锁） | **ADMIN-OVERRIDE** 触发每种无人机专属技能、继承 Operator 物品；SWARM 是统一 450% 冲撞、暴击点燃替代 |
| 位移 | `Ascent Protocol`（默认）；`FIREWALL`（挑战解锁） | **Ascent Protocol** 多无人机接力飞行，Eclipse 机动首选；FIREWALL 是挡伤+发射 200%–600% 控线替代 |
| 特殊 | `Ejection Core`（默认）；`Amp Core`（挑战解锁） | **Ejection Core** 300%、击飞并 Nano-Bug 增伤，稳定控制；Amp Core 吸收攻击后 300%–2000% 爆炸、能诱敌但需要蓄伤 |

推荐：Gunner+Healing，`H3-11 / ADMIN-OVERRIDE / Ascent Protocol / Ejection Core`。

## 无人机经济、触发与生存

- ADMIN-OVERRIDE 的命令攻击通常算 Operator 的攻击，使用他的伤害、on-hit/on-kill 物品；每种无人机有不同命令。无人机越多，最大命令层数越高。
- Drone Combiner 合并同类无人机后保留/增加命令库存，并让 ADMIN-OVERRIDE 效果按 tier 线性提高；该伤害提高不适用于 CMD-SWARM。
- 不要为了买每台无人机拖慢整关：前期优先便宜功能型，Boss 前留命令层；合并同类比无限修低级无人机更有效。
- 1.4.1 修复 Pocket I.C.B.M. 对 Missile Drone 命令、若干跨关物品和 Operator 互动；Amp Core 本体被攻击不再触发 on-hit。

## 物品优先级（编辑判断）

- **白：** `Mocha` **3–5**；`Lens-Maker's Glasses` 满暴击（SWARM 点燃/通用 proc）；`Armor-Piercing Rounds` **1–3**；`Delicate Watch` **1–3**；`Oddly-shaped Opal` **1**。
- **绿：** `Box of Dynamite` **1–3**（无人机周期投炸药，Operator 有专属命令）；`AtG Missile Mk. 1`/`Ukulele` 各 **1–3**；`Fuel Cell` **1–2**；`Shipping Request Form` **1**（腾金币买无人机）。
- **红：** `Spare Drone Parts` **1**（AC 官方减半后仍明确强）；`Pocket I.C.B.M.` **1**（Missile Drone 命令已修复）；`57 Leaf Clover` **1**；`Orphaned Core` **1** 条件（Best Buddy 不能被常规命令，但补独立追击）。
- **首领：** `Empathy Cores` **1+**（盟友数放大）；`Defense Nucleus` **1**；`Queen's Gland` **1** 扩队伍规模。
- **装备：** `The Back-up` 扩无人机波次；`Executive Card` 可从 Triple Drone Shop 获取更多购买价值；后期换 `Royal Capacitor`。
- **装备替代：** AC 的 `Deus Ex Machina` 可反制一次任意伤害并强化下一击的 on-hit；要求主动读招，熟练玩家 **1** 条件。

## 单人 Command 路线

- **前期：** Mocha×2、眼镜×3、Opal→Box of Dynamite；优先买 2–4 台不同功能无人机，不为远处昂贵无人机超时。
- **中期：** AtG/Ukulele、Fuel Cell、Shipping Request Form；合并常见无人机，Boss 前储满 ADMIN 层。
- **后期：** `Spare Drone Parts`→`Pocket I.C.B.M.`/Clover，取 Empathy Cores/Defense Nucleus，补 Dio/Safer Spaces。

## 联机调整

Operator 与 Engineer 对 `Spare Drone Parts`、Box of Dynamite、无人机购买冲突最大；开局约定一个机械主核，或平均分配。无人机商店金币来自个人但火力服务全队；让持 `Executive Card` 的人购买三联店。Healing Drone 命令给队友加速/治疗，Mk 2 DOC 命令给屏障；不要只为个人 DPS 排队。

## Void 转换

- **推荐：** `Polylute`←`Ukulele`，ADMIN 多命令的单体链强；无人机炸药已有 AoE。
- **推荐：** `Plasma Shrimp`←`AtG Missile Mk. 1`，DOC 屏障和远程飞行帮助维持护盾；掉盾环境保留 AtG。
- **条件：** `Lysate Cell`←`Fuel Cell`，额外 Ejection/Amp；若 The Back-up 是主核则保留 Fuel Cell。
- **条件：** `Needletick`←`Tri-Tip Dagger`，命令高频短战强。
- **避免：** `Benthic Bloom`，可能随机升级掉经济/无人机指定组件。

## Lunar 被动与装备

- **条件推荐：** `Gesture of the Drowned`+The Back-up 自动扩军；无法给 Boss 留波次。
- **条件：** `Transcendence` 配 DOC 屏障/远程飞行，常规 Healing Drone 治疗会失效。
- **条件：** `Shaped Glass` 同时放大 Operator 命令伤害但把本体变脆；无人机不会替你承担所有攻击。
- **避免：** `Brittle Crown`：飞行/指挥时被擦伤会丢钱，直接拖慢无人机经济。

## 战斗循环

- **传送器：** 储满 ADMIN→Ejection Core 上 Nano-Bug→依无人机队列连续命令→H3-11 充能点杀→Ascent 接力躲线。
- **Boss：** 先命令控制/增益无人机，再放伤害无人机；合并高 tier 命令留给 Boss 硬直窗。
- **飞行怪：** H3-11 满充点杀，Gunner/Missile 命令追击；Ascent 保持制高但留一个落点。
- **最终阶段：** 无人机可跟进 Hidden Realms 是优势；Ascent 跨旋转墙，物品夺取阶段靠无人机吸引/命令控制，别追进锤击中心。
