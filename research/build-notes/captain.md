# 舰长 Captain

## 版本与来源

核验于 2026-08-25。角色/技能/信标：https://riskofrain2.wiki.gg/wiki/Captain ；proc：https://riskofrain2.wiki.gg/wiki/Proc_Coefficient ；物品：https://riskofrain2.wiki.gg/wiki/Items 。推荐为编辑判断。

## 角色定位

中距离霰弹 proc、轨道控场和一次性每关经济/支援信标。被动 `Defensive Microbots` 会拦截附近投射物，并由无人机继承；但在部分 Hidden Realms 中轨道技能不可用，不能把信标当唯一生存手段。

## 当前技能与推荐配置

| 槽位 | 选择与解锁 | 推荐 |
|---|---|---|
| 主技能 | `Vulcan Shotgun`（默认、唯一） | 蓄力收紧散布；固定 |
| 副技能 | `Power Tazer`（默认、唯一） | 眩晕普通目标；固定 |
| 位移/轨道 | `Orbital Probe`（默认）；`OGM-72 'DIABLO' Strike`（挑战解锁） | **Orbital Probe** 延迟短、三次稳定；DIABLO 20 秒且伤及所有角色，仅娱乐/预判 |
| 特殊 | `Orbital Supply Beacon`，两格各选 `Beacon: Healing`（默认）、`Beacon: Shocking`（默认）、`Beacon: Resupply`（挑战）、`Beacon: Hacking`（挑战） | 单人最稳 **两枚 Hacking**；Boss/无经济关可 Hacking+Healing |

推荐：`Vulcan Shotgun / Power Tazer / Orbital Probe / Hacking + Hacking`。信标落地后不可回收，每关只用一次。

## 伤害、移动与生存

- Vulcan Shotgun 8 弹丸各 0.75 proc，蓄力只收紧散布，不增加总伤；近距/大目标触发极密。
- Hacking 把附近以金币购买的对象逐个降到 0，可免费传奇箱、无人机、机会神龛；不能免费月球币对象。
- Captain 无原生位移，移速/跳跃是第一优先；Tazer→Probe 让目标停在落点。

## 物品优先级（编辑判断）

- **白：** `Mocha` **3–5**、`Paul's Goat Hoof` **3–5**（补无位移）；`Tri-Tip Dagger` 做到流血等效；`Lens-Maker's Glasses` 做到满暴击；`Oddly-shaped Opal` **1**。
- **绿：** `AtG Missile Mk. 1`、`Ukulele` 各 **1–3**；`Hopoo Feather` **2**；`Shipping Request Form` **1+**（每关经济，与信标共提节奏）；`Fuel Cell` **1–3**。
- **红：** `57 Leaf Clover` **1**；`Brilliant Behemoth` **1**；`Spare Drone Parts` **1**（无人机继承 Microbots，AC 后仍强）。
- **首领：** `Empathy Cores` **1**（盟友/无人机体系）；`Defense Nucleus` **1**；`Charged Perforator` **1+**。
- **装备：** `Executive Card` 经济首选；成型后 `Royal Capacitor`。Resupply Beacon 可立即充装备三次，若选它可用长 CD `Preon Accumulator`。

## 单人 Command 路线

- **前期：** Mocha/Goat Hoof 各×2→Opal→眼镜/流血；Hacking 优先最大箱或无人机三联店。
- **中期：** AtG、Ukulele、Hopoo Feather×2、Shipping Request Form；燃料电池配装备。
- **后期：** Clover/Behemoth→Spare Drone Parts（已有无人机）→Dio；最终关信标不一定可用，提前补纯物品机动。

## 联机调整

Hacking 信标会替全队省钱，应落在传奇箱/无人机商店或多个对象密集处并先沟通。`Executive Card` 只需一人拿；Spare Drone Parts 与 Operator 冲突，若 Operator 为无人机核心则让他。Healing Beacon 是公共站点，Shocking 可保护无位移后排。

## Void 转换

- **推荐：** `Polylute`←`Ukulele`，霰弹高 proc 加强单体；队伍已有清群时。
- **推荐：** `Lysate Cell`←`Fuel Cell`，额外信标充能；注意只对第一/主信标配置的效果最明确，装备流则保留 Fuel Cell。
- **推荐（经济）：** `Encrusted Key`←`Rusted Key`，每关 Void 缓存提供三选一；会腐化全部生锈钥匙。
- **条件：** `Needletick`←`Tri-Tip Dagger`，霰弹快速叠坍缩，短战强。
- **条件：** `Plasma Shrimp`←`AtG Missile Mk. 1`，Microbots 与走位能保盾时。
- **避免：** `Benthic Bloom`，会破坏 Hacking/Command 的精确经济构筑。

## Lunar 被动与装备

- **推荐（机动修复）：** `Strides of Heresy` 替换轨道 Utility，获得无敌移动/治疗；代价是失去 Probe/DIABLO，Hidden Realm 反而实用。
- **条件：** `Gesture of the Drowned` 配主动装备；与 Resupply Beacon 的“留装备”策略冲突。
- **条件：** `Transcendence` 解决低机动挨擦伤后的恢复，但 Healing Beacon 失效。
- **条件：** `Focused Convergence` 缩小传送器区域并加快充能；Captain 无位移，区域过小会更危险，只有清场/移速成型时拿。
- **避免：** `Brittle Crown`，无位移时更容易受击丢钱，削弱 Captain 的经济优势。

## 战斗循环

- **传送器：** Hacking 先换资源→Tazer 定精英→Probe 预判落点→蓄紧 Shotgun 近中距触发。
- **Boss：** 三次 Probe 交错落点，近距霰弹打满；明显大招前远离，Captain 没有紧急 dash。
- **飞行怪：** 蓄力霰弹收紧散布，电容器点杀；Probe 对高速空怪不稳。
- **最终阶段：** 依赖 Hopoo/移速而非轨道救场；柱子前放可用信标，米斯历克斯物品夺取阶段用地形和 Tazer 控小怪。
