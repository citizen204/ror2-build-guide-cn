# 女猎人 Huntress

## 版本与来源

核验于 2026-08-25。角色/技能：https://riskofrain2.wiki.gg/wiki/Huntress ；触发系数：https://riskofrain2.wiki.gg/wiki/Proc_Coefficient ；物品：https://riskofrain2.wiki.gg/wiki/Items 。推荐为编辑判断，机制描述为事实摘要。

## 角色定位

锁定射击、全速奔跑中输出的高机动清群角色。基础生命偏低，优势是几乎不需要牺牲走位来瞄准；短板是射程/锁定限制与单体倍率，Eclipse 要靠位移次数和爆发窗口而不是持续换血。

## 当前技能与最稳单人配置

| 槽位 | 选择与解锁 | 编辑判断 |
|---|---|---|
| 主技能 | 扫射 `Strafe`（默认）；乱射 `Flurry`（挑战解锁） | **Strafe** 前期稳定；满暴击后 Flurry 明显放大箭数，可条件切换 |
| 副技能 | 激光飞刃 `Laser Glaive`（默认、唯一） | 固定清群核心 |
| 位移 | 闪现 `Blink`（默认）；相位闪现 `Phase Blink`（挑战解锁） | **Blink** 有垂直量且一次脱险更稳；Phase Blink 三层短移适合熟练玩家 |
| 特殊 | 箭雨 `Arrow Rain`（默认）；弩炮 `Ballista`（挑战解锁） | **Ballista** 单体、远程和空中停滞都更可靠 |

推荐：`Strafe / Laser Glaive / Blink / Ballista`。Command 能很快满暴击时改 `Flurry`；大量地面小怪、需持续区域控制时才用 `Arrow Rain`。

## 触发、伤害与生存模式

- `Laser Glaive` 在目标间反弹并逐跳增伤，先锁小怪可把后续高倍率送到精英；空旷单 Boss 时价值下降。
- `Ballista` 三发独立强击适合手环、撬棍与穿甲；开火期间利用空中悬停微调。
- 锁定不是无条件命中：遮挡和射程仍会断输出。全程冲刺、斜向绕圈，闪现留给致命线。

## 构筑逻辑与分层优先级（编辑判断）

### 白色

- `Lens-Maker's Glasses`：Strafe 需要暴击，Flurry 更依赖；Command 目标 **10 件等效**。
- `Energy Drink`：冲刺中仍能射击，收益高于多数角色；**3–5**。
- `Backup Magazine`：更多飞刃直接提升清群；**2–4**。
- `Crowbar`：Ballista 与飞刃首击放大；**1–3**。
- `Oddly-shaped Opal`：低血线首击保护；**1**。

### 绿色

- `Hopoo Feather`：与 Blink 叠垂直安全；**1–2**。
- `Kjaro's Band` + `Runald's Band`：Ballista 稳定触发；各 **1**，后续加 Kjaro 提清群。
- `Ukulele`：让 Strafe 也能扩散；**1–2**。
- `Rose Buckler`：常驻冲刺护甲；**1–3**。

### 红色

- `Hardlight Afterburner`：多次 Blink 是最直接的 Eclipse 生存红；**1**。
- `Laser Scope`：满暴击放大 Flurry/Ballista；**1**。
- `57 Leaf Clover`：通用触发链；**1**。
- `Sentient Meat Hook`：补聚怪并让飞刃继续反弹；**1** 条件。

### 首领与装备

- `Little Disciple`：冲刺常驻，自动清理近身怪；**1+**。
- `Shatterspleen`：满暴击后补爆炸与流血；**1**。
- `Royal Capacitor`：补远距离单点。
- `Gorag's Opus`：队伍/自身攻速移速爆发，适合传送器；需要更强经济则先 `Recycler`。

## 单人 Command 路线

- **前期：** `Energy Drink`×2、眼镜×3、备用弹匣×1、蛋白石×1；先让“边跑边打”成立。
- **中期：** Command 直接满暴击并切 Flurry，取双手环、羽毛、Rose Buckler。
- **后期：** `Hardlight Afterburner`→`Laser Scope`/`57 Leaf Clover`；补 `Dio's Best Friend` 防止低血量失误。

## 联机调整

女猎人能低成本处理空中小怪和清场，优先把撬棍/手环让 Railgunner、Loader，把无人机红让 Operator/Engineer。自己争取移速与羽毛；若队伍治疗少，可把 `Harvester's Scythe` 留给更高触发且更常受击的前排，依靠走位与食物恢复。

## Void 转换

- **推荐：** `Safer Spaces`←`Tougher Times`，闪现间隔内提供可计划的保险。
- **条件：** `Polylute`←`Ukulele`，Boss 压力大且队伍已有清群时换。
- **条件：** `Plasma Shrimp`←`AtG Missile Mk. 1`，只有护盾能稳定维持时换。
- **避免：** `Lost Seer's Lenses`←`Lens-Maker's Glasses`，会摧毁 Flurry/Scope/Shatterspleen 的暴击核心。
- **避免：** `Benthic Bloom`←`57 Leaf Clover`，Command 精确构筑不值得被随机升级打散。

## Lunar 被动与装备

- **推荐：** `Gesture of the Drowned` 配主动伤害装备，Huntress 可持续跑动让自动释放风险较小；仍会失去留技能时机。
- **条件：** `Shaped Glass` 放大 Ballista，但低生命和 Eclipse 永久伤使失误代价极高。
- **条件：** `Light Flux Pauldron` 加快技能冷却却减攻速；Ballista/飞刃技能流可拿，Flurry 流避免。
- **避免：** `Brittle Crown`，低血量角色被擦伤就掉钱，前期经济不稳定。

## 战斗循环

- **传送器：** 全程冲刺绕圈，飞刃投向小怪群，Ballista 点精英；Blink 穿过攻击线而非无目的赶路。
- **Boss：** Ballista→持续 Strafe/Flurry→飞刃借杂兵增伤；攻击预兆出现后再 Blink。
- **飞行怪：** 锁定主技能天然处理；皇家电容器点杀飞行精英。
- **最终阶段：** 用 Blink 保留垂直/横向余量，月球碎片/旋转墙阶段不要一次交空全部位移。
