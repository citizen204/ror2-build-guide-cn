# 盗贼 Bandit

## 版本与来源

核验于 2026-08-25。角色/技能：https://riskofrain2.wiki.gg/wiki/Bandit ；暴击与触发：https://riskofrain2.wiki.gg/wiki/Proc_Coefficient ；物品：https://riskofrain2.wiki.gg/wiki/Items 。推荐标签均为编辑判断。

## 角色定位

靠背后必定暴击、隐身重定位与特殊技能处决滚雪球的近中距离爆发手。技能顺序和站位比无脑堆暴击更重要；单人可用 `Desperado` 永久累积本关伤害，联机则更难稳定抢到处决。

## 当前技能与最稳单人配置

| 槽位 | 选择与解锁 | 编辑判断 |
|---|---|---|
| 主技能 | 爆裂射击 `Burst`（默认）；爆破射击 `Blast`（挑战解锁） | **Burst** 近中距总倍率/触发更强；Blast 远距更准 |
| 副技能 | 锯齿匕首 `Serrated Dagger`（默认）；锯齿飞刀 `Serrated Shiv`（挑战解锁） | **Serrated Shiv** 安全施加 Hemorrhage；纯贴身速杀可 Dagger |
| 位移 | 烟雾弹 `Smoke Bomb`（默认、唯一） | 隐身、眩晕、跳跃重定位；固定 |
| 特殊 | 熄灯 `Lights Out`（默认）；亡命徒 `Desperado`（挑战解锁） | **Desperado** 单人最强长期倍率；联机/短局可 Lights Out 重置 |

推荐：`Burst / Serrated Shiv / Smoke Bomb / Desperado`。`Blast` 是远程手感替代；`Lights Out` 适合队友容易抢尾刀或需要频繁刷新烟雾弹的场景。

## 触发、伤害与生存模式

- 被动 `Backstab` 让背后攻击必暴击；不代表正面已有满暴击，因此物品暴击仍能提高正面可靠性，但 Command 不必第一时间堆满。
- `Serrated Shiv/Dagger` 从背后命中会施加 Hemorrhage，长 Boss 战价值很高。
- Desperado 必须用该技能完成击杀才加本关层数；前期先用普通攻击压血，再用左轮收尾。
- Smoke Bomb 是脱锁、眩晕、垂直修正和背后定位的总枢纽，不能只当赶路。

## 构筑逻辑与分层优先级（编辑判断）

### 白色

- `Crowbar`：Desperado/背刺首击；**3–5** 后转通用倍率。
- `Armor-Piercing Rounds`：Boss 与最终战；**1–3**。
- `Backup Magazine`：飞刀层数与容错；**2–3**。
- `Mocha`：换弹/攻击手感与移动；**2–4**。
- `Topaz Brooch`：处决小怪叠屏障；**1–2**。

### 绿色

- `Kjaro's Band`、`Runald's Band`：背刺/Desperado 高倍率触发；各 **1**，不要无脑叠 Runald。
- `Shuriken`：近战主攻时补远程和手环触发；**1–3**。
- `Old Guillotine`：精英处决阈值帮助滚雪球；**1–2**。
- `Hopoo Feather`：与 Smoke Bomb 组合保持制高；**1**。

### 红色

- `Laser Scope`：背后必暴击直接吃倍率；**1**。
- `Brilliant Behemoth`：每次高倍率击发扩散；**1**。
- `Alien Head`：减少关键技能空窗；**1**。

### 首领与装备

- `Shatterspleen`：背刺必暴击使其非常稳定，兼容 Hemorrhage；**1**。
- `Molten Perforator`：高伤击发带来强火焰 proc；**1+**。
- `Ocular HUD`：正面/远处强制暴击，适合无法绕背的 Boss；已有满暴击后换掉。
- `Preon Accumulator`：撬棍/手环爆发开 Boss；长冷却要求留给传送器。

## 单人 Command 路线

- **前期：** 撬棍×3、Mocha×2、备用弹匣×1、蛋白石×1；优先建立 Desperado 安全收尾线。
- **中期：** 双手环、手里剑、羽毛、旧断头台；正面暴击补到约 50% 即可，资源转倍率。
- **后期：** `Laser Scope`→`Brilliant Behemoth`，补 Clover 与复活；每关先刷一批 Desperado 层再开传送器。

## 联机调整

Desperado 尾刀会和队友清场冲突：开局说明需要留一波低血小怪，或改 `Lights Out`。撬棍/手环与 Railgunner/Loader 强冲突，应按谁承担 Boss 爆发分配；盗贼天然背刺暴击，可把早期眼镜让给 Huntress/Commando。不要在队友视野外长时间刷层拖慢计时。

## Void 转换

- **推荐：** `Voidsent Flame`←`Will-o'-the-wisp`，满血首击与撬棍/背刺爆发协同。
- **条件：** `Needletick`←`Tri-Tip Dagger`，短战延迟爆发可用；长期 Hemorrhage/流血构筑保留原件。
- **条件：** `Lysate Cell`←`Fuel Cell`，只有当装备价值低而想多一层 Desperado/Lights Out 时换。
- **避免：** `Lost Seer's Lenses`，虽然背面仍会暴击，但它会腐化全部眼镜、令正面暴击与 Scope 体系崩坏。
- **避免：** `Plasma Shrimp`，盗贼常在近距离挨擦伤，护盾断时收益消失。

## Lunar 被动与装备

- **推荐（高熟练）：** `Purity` 降 Smoke Bomb/特殊技能冷却；代价是负幸运，必须明确放弃 proc 流，转纯倍率爆发。
- **条件：** `Shaped Glass` 把撬棍背刺推入处决线，但容错减半。
- **条件：** `Gesture of the Drowned` 配 Preon 会乱放，配 Royal Capacitor 才相对可控。
- **避免：** `Visions of Heresy` 会替换很适合背刺的 Burst；除非正在组 Heretic 四件套。

## 战斗循环

- **传送器：** 先用 Desperado 收小怪→Smoke Bomb 穿到精英背后→Shiv→Burst→特殊收尾。
- **Boss：** 背后维持 Hemorrhage；Boss 转身/出招时隐身换侧，装备+手环打爆发窗。
- **飞行怪：** Shiv/Blast/特殊点杀；不要为背刺跳进空中失去落点。
- **最终阶段：** Smoke Bomb 留给旋转墙和锤击；物品夺取阶段从背后 Burst，避免正面贪换弹。
