# 装载机 Loader

## 版本与来源

核验于 2026-08-25。角色/技能：https://riskofrain2.wiki.gg/wiki/Loader ；proc：https://riskofrain2.wiki.gg/wiki/Proc_Coefficient ；物品：https://riskofrain2.wiki.gg/wiki/Items 。推荐为 Monsoon/Eclipse 稳定通关的编辑判断。

## 角色定位

以钩索蓄积速度、用 `Heavy` 拳把速度转成单击伤害的高机动爆发手。默认被动 `Scrap Barrier` 免疫坠落伤害，并由 Knuckleboom/两种拳命中获得屏障；Pylon 和 Thunderslam 不产屏障。

## 当前技能与推荐配置

| 槽位 | 选择与解锁 | 推荐 |
|---|---|---|
| 主技能 | `Knuckleboom`（默认、唯一） | 固定，落拳后补屏障 |
| 副技能 | `Grapple Fist`（默认）；`Spiked Fist`（挑战解锁） | **Spiked Fist** 带伤害/眩晕，重目标仍拉自己 |
| 位移 | `Charged Gauntlet`（默认）；`Thunder Gauntlet`（挑战解锁） | **Charged Gauntlet** 穿透群体、最高速度上限更适合熟练稳定；Thunder 充能快且锥形伤害，是易用替代 |
| 特殊 | `M551 Pylon`（默认）；`Thunderslam`（挑战解锁） | **Thunderslam** 2000% 落地眩晕和 Boss 爆发；Pylon 用于对空/proc/钩索锚点 |

推荐：`Knuckleboom / Spiked Fist / Charged Gauntlet / Thunderslam`。飞行怪密集或需要安全触发链时改 `M551 Pylon`。

## 伤害、移动与生存

- 钩重目标荡到切线最高速，再在速度峰值释放 Charged Gauntlet；Heavy 伤害随当前速度增加。
- 一拳命中后继续飞离目标，不在 Boss 面前急停。主拳空窗用钩索/冲刺保存动量。
- 屏障来自有效近战命中；高难度仍要靠路径规避，屏障不是硬抗许可。

## 物品优先级（编辑判断）

- **白：** `Crowbar` **5–10**（满血一拳）；`Paul's Goat Hoof` **3–5**（速度即伤害）；`Focus Crystal` **3–5**（近距乘区）；`Armor-Piercing Rounds` **1–3**；`Oddly-shaped Opal` **1**。
- **绿：** `Kjaro's Band`+`Runald's Band` 各 **1**（拳稳定触发）；`Wax Quail` **1–2**；`Hopoo Feather` **1**；`Shuriken` **1–3**（空窗远程触发环）。
- **红：** `Hardlight Afterburner` **1**（多拳充能）；`H3AD-5T v2` **1**（Loader 免坠伤、重砸爆发）；`Brilliant Behemoth` **1**。
- **首领：** `Shatterspleen` **1**（暴击一拳爆群）；`Charged Perforator` **1+**（强击 proc）。
- **装备：** `Preon Accumulator` 开 Boss 双爆发；`Ocular HUD` 让拳必暴击，满暴击后换 `Royal Capacitor`。

## 单人 Command 路线

- **前期：** Goat Hoof×2→Crowbar×3→Focus Crystal×2→Opal；先让摆荡与一拳阈值成立。
- **中期：** 双手环、Wax Quail/Feather、更多撬棍与穿甲；不要优先堆攻速。
- **后期：** `Hardlight Afterburner`→`H3AD-5T v2`/Behemoth，补 `Dio's Best Friend` 与 Safer Spaces。

## 联机调整

Loader 是撬棍/手环第一优先候选，与 Railgunner/Bandit 协商一人一套；把攻速、持续 proc 与无人机件让队友。负责快速开远处箱和点杀精英，但别把 Boss 拉出传送器/队伍 AoE。队友已控制飞行群时选 Thunderslam，否则保留 Pylon。

## Void 转换

- **推荐：** `Voidsent Flame`←`Will-o'-the-wisp`，满血拳+撬棍同步。
- **推荐：** `Safer Spaces`←`Tougher Times`，两次进场之间可等格挡恢复。
- **条件：** `Lysate Cell`←`Fuel Cell`，多一次 Thunderslam/Pylon；装备是开场核心则保留 Fuel Cell。
- **条件：** `Polylute`←`Ukulele`，单体强化，但 Loader 原本清群有限时需 Behemoth/环补足。
- **避免：** `Needletick`，低频重击不适合叠坍缩。

## Lunar 被动与装备

- **推荐（高熟练）：** `Purity` 减拳/钩冷却；负幸运代价对纯倍率一拳流较小。
- **条件：** `Shaped Glass` 能极大提高一拳线，但减半生命；只在路径熟练且有复活时。
- **条件：** `Light Flux Pauldron` 加速技能但减攻速，纯技能流可接受。
- **避免：** `Strides of Heresy` 替换 Charged Gauntlet，直接破坏核心移动伤害循环（除非转 Heretic）。

## 战斗循环

- **传送器：** 钩边缘重目标/地形→蓄拳穿精英群→Thunderslam 落地→继续飞离。
- **Boss：** 预先拉长摆荡，速度峰值拳+双环；Boss 出招期间绕场积速。
- **飞行怪：** Spiked Fist 拉近后拳穿过，或 Pylon 慢清；不在空中失去下一锚点。
- **最终阶段：** 钩柱子/场边避锤与旋转墙；物品夺取阶段仍有免坠伤和基础机动，打一拳即撤。
