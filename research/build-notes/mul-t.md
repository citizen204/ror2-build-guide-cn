# MUL-T

## 版本与来源

核验于 2026-08-25。角色/技能：https://riskofrain2.wiki.gg/wiki/MUL-T ；触发系数：https://riskofrain2.wiki.gg/wiki/Proc_Coefficient ；物品：https://riskofrain2.wiki.gg/wiki/Items 。推荐为编辑判断。

## 角色定位

高生命、可携带两套主武器/装备的持续火力平台。`Retool` 配置能在两把武器和两个装备间切换；`Power Mode` 配置则牺牲机动换双持和护甲。稳定单人以远近兼顾、保留 Transport Mode 脱险最普适。

## 当前技能与最稳单人配置

| 槽位 | 选择与解锁 | 编辑判断 |
|---|---|---|
| 主技能 | 自动钉枪 `Auto-Nailgun`（默认）；钢筋发射器 `Rebar Puncher`（默认）；废料发射器 `Scrap Launcher`（挑战解锁）；电锯 `Power-Saw`（挑战解锁） | **双 Rebar Puncher** 配 Retool 可交替高频击发；普通游玩可 Nailgun+Rebar |
| 副技能 | 爆破罐 `Blast Canister`（默认、唯一） | 固定眩晕/清群 |
| 位移 | 运输模式 `Transport Mode`（默认、与 Retool 同组）；动力模式 `Power Mode`（挑战解锁后占特殊槽并改变配置） | **Transport Mode** 更适合 Eclipse 撤离 |
| 特殊 | 重整 `Retool`（默认）；动力模式 `Power Mode`（挑战解锁） | **Retool** 稳定性/双装备；Power Mode 双 Nailgun 是定点持续火力替代 |

推荐：两把 `Rebar Puncher`、`Blast Canister / Transport Mode / Retool`；如果不使用切枪节奏，则 `Auto-Nailgun + Rebar Puncher`。条件方案：`Power Mode` 双 Nailgun 对单体很强，但定身和短射程在 Eclipse 风险更高。

## 触发、伤害与生存模式

- Rebar 是高倍率、1.0 proc 单发，适合撬棍/手环；双 Rebar 通过 Retool 轮换绕过单把充能节奏。
- Nailgun 是高频低单击倍率，适合流血、AtG、Ukulele；需贴到中距控制散布。
- Transport Mode 提速、护甲并撞击，主要用来跨越危险区；不要把退出冲撞当主要 Boss 输出。
- MUL-T 生命高但体型大，命中面也大；移速与羽毛依然优先。

## 构筑逻辑与分层优先级（编辑判断）

### 白色

- `Crowbar`：Rebar 首击；双 Rebar **3–5**。
- `Soldier's Syringe`：Nailgun/Power Mode；**3–6**，双 Rebar 不必堆。
- `Tri-Tip Dagger`：Nailgun 高频流血；做到 **10 件等效**。
- `Paul's Goat Hoof`：改善大体型走位；**3–5**。
- `Oddly-shaped Opal`：进出 Power Mode/换枪时抗首击；**1**。

### 绿色

- `Kjaro's Band`、`Runald's Band`：Rebar 稳定触发；各 **1**。
- `AtG Missile Mk. 1`：两类主武器都通用；**1–3**。
- `Wax Quail`：冲刺跳躲线；**1**。
- `Fuel Cell`：Retool 两套装备也受益；**1–3**。

### 红色

- `Hardlight Afterburner`：Transport Mode 多层充能，生存首选；**1**。
- `Brilliant Behemoth`：Rebar 补范围、Nailgun 提每击伤；**1**。
- `Pocket I.C.B.M.`：导弹装备/AtG 构筑时质变；**1**。

### 首领与装备

- `Shatterspleen`：Nailgun 暴击流血爆炸；**1**。
- `Genesis Loop`：高生命提供低血清场保险，但不要主动卖血；**1**。
- `Preon Accumulator` + `Royal Capacitor`：Retool 可分别携带开场爆发与短 CD 点杀。
- `Executive Card`：第二装备位保留经济、战斗位用电容器，是 Retool 独有优势之一。
- `Disposable Missile Launcher`：导弹流配 `Pocket I.C.B.M.` 的稳定装备；Retool 可在另一格保留工具。

## 单人 Command 路线

- **前期：** 双 Rebar 路线取撬棍×3、山羊蹄×2、蛋白石；Nailgun 路线改注射器+流血。
- **中期：** Rebar 取双手环，通用取 AtG、羽毛/蜡鹌鹑、燃料电池；搜两件不同功能装备。
- **后期：** `Hardlight Afterburner`→`Brilliant Behemoth`；导弹件足够时选 `Pocket I.C.B.M.`，补复活。

## 联机调整

双装备会与队伍争抢橙装，先约定只拿一个主战装备，第二格放经济/工具。Rebar 路线与 Loader/Railgunner 争撬棍手环；Nailgun 路线则拿他们不需要的攻速/流血。把 `Spare Drone Parts` 让 Operator/Engineer，把治疗让更脆的前排。

## Void 转换

- **推荐：** `Polylute`←`Ukulele`，双 Rebar 缺单体连锁时很强。
- **推荐（Nailgun）：** `Needletick`←`Tri-Tip Dagger`，短战触发快；长 Boss 保留流血。
- **条件：** `Plasma Shrimp`←`AtG Missile Mk. 1`，MUL-T 护盾构筑可维持；否则被擦伤掉价值。
- **条件：** `Lysate Cell`←`Fuel Cell`；Power Mode/额外特殊层有价值，Retool 双装备流不要腐化全部燃料电池。
- **避免：** `Benthic Bloom` 会打散 Command 精确的双武器分支。

## Lunar 被动与装备

- **推荐（构筑闭环）：** `Transcendence` 利用高基础生命转大护盾；会禁用常规治疗，必须打脱战回盾节奏。
- **条件：** `Gesture of the Drowned` 对 Retool 当前装备自动触发，可能误用经济装备；只在两格都适合自动释放时拿。
- **条件：** `Light Flux Pauldron` 对双 Rebar/技能路线有利，却砍 Nailgun 攻速；Power Mode Nailgun 禁拿。
- **条件：** `Spinel Tonic` 在有 Gesture/Fuel Cell 保证高覆盖时强化 Power Mode；断档会积累 Tonic Affliction，未闭环避免。
- **避免：** `Shaped Glass` 把大生命优势直接减半，除非已有极强机动与保险。

## 战斗循环

- **传送器：** Rebar→Retool→Rebar 轮换点精英，Canister 打断群体，Transport Mode 穿过包围圈。
- **Boss：** 双装备开场→双 Rebar 手环节奏；Nailgun 则保持中近距离、危险招式前退出 Power Mode。
- **飞行怪：** Rebar/Canister 优先，电锯仅清理贴身地怪。
- **最终阶段：** Transport Mode 不要提前耗掉；柱子阶段用第二装备工具，物品被夺时靠高基础生命与掩体拖回关键机动。
