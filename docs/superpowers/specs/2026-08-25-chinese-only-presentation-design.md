# 全中文展示设计

## 背景与目标

现有网站同时展示中文名与英文名，并在部分构筑正文中直接使用英文技能、物品和机制词。用户希望网页改为全中文阅读体验，不再出现中英并列，但仍需要英文搜索能力。

本次改动的目标是：所有用户可见的攻略内容只显示中文，同时保留内部英文数据，以支持英文搜索、资源匹配和内容维护。

## 已确认的边界

- 采用“中文展示、双语数据保留”的方式。
- 页面不再并列显示角色、技能、物品和腐化原物品的英文名。
- `MUL-T`、`REX` 等游戏官方本身使用拉丁字母的专名可以保留，但只显示一次。
- DLC 筛选和适用范围使用中文全称：“本体”“虚空幸存者”“风暴探寻者”“合金意念”“特殊变身”。
- 英文名继续保存在领域数据中，不从数据模型删除。
- 英文角色搜索继续有效，例如输入 `Acrid` 仍可找到“呛鼻毒师”。
- 网站仍是普通浏览器网页，不改变为游戏插件或悬浮层。

## 展示设计

### 首页

- 角色卡标题仅显示 `nameZh`；官方拉丁专名直接由 `nameZh` 提供，不再追加 `nameEn`。
- 角色头像替代文本仅使用展示名称，例如“呛鼻毒师角色头像”。
- DLC 筛选按钮与角色卡标签全部使用中文全称，不显示缩写。
- 搜索输入框继续接受中文名和英文名，搜索结果中不提示英文命中词。

### 角色详情页

- 角色主标题、头像替代文本、上一篇/下一篇角色名称仅显示中文展示名。
- 技能列表只显示技能中文名；解锁状态、槽位和推荐理由保持中文。
- 物品列表只显示物品中文名；腐化原物品也只显示中文名。
- 统率神器路线只显示中文物品名。
- 八个主章节、月球被动物品与月球主动装备的分组结构保持不变。
- 不通过隐藏样式保留英文节点，避免屏幕阅读器或复制文本时再次暴露英文。

### 正文内容

19 份角色数据中的以下可见字段必须中文化：

- `role`、`summary`
- `skills[].reason`
- `buildLogic[]`
- `solo`、`voidItems`、`lunarItems`、`lunarEquipment` 中每个物品选择的 `stacks`、`role`、`synergy`、`alternative`
- `coopAdjustments[]`
- `commandRoute[].explanation`
- `combatNotes[].title` 与 `combatNotes[].body`

英文技能名和物品名应替换为既有 `nameZh`；机制词使用统一中文表达，例如“暴露”“削弱”“腐化值”“重型攻击”“成长”“垃圾资源”。不使用运行时字符串替换，以免误改普通单词或漏掉上下文含义。

## 数据与搜索

- `nameEn` 字段继续保留在 `SurvivorGuide`、`SkillChoice` 和 `ItemDefinition` 中。
- 搜索逻辑继续使用角色的 `nameZh`、`nameEn` 和 `slug`，因此英文角色搜索不受影响。
- 可见组件不得渲染 `nameEn`，但测试和维护工具仍可读取它。
- 本次不扩展为全站物品或技能搜索；只保留现有角色搜索能力。

## 英文残留规则

可见页面原则上不允许拉丁字母。允许项仅限：

- 游戏官方专名 `MUL-T` 与 `REX`。
- URL、代码标识、文件名和不会渲染到页面的内部数据。

如果后续确认其他官方中文本地化仍以拉丁字母显示，应显式加入维护清单，不能用宽泛正则豁免所有大写词。

## 元数据、页脚与项目说明

- HTML 标题和描述保持中文，并移除可见描述中的 `Alloyed Collective`。
- 页脚适用范围只显示中文 DLC 名称；外部链接标题使用中文。
- 图标来源链接的 URL 可以包含英文路径，但链接可见文字必须是中文。
- 更新 `PRODUCT.md` 与 README，说明页面改为全中文展示、英文仅用于搜索和内部维护。

## 测试策略

### 失败测试先行

1. 首页测试先断言角色卡、DLC 筛选和图片替代文本不再渲染并列英文。
2. 详情页测试先断言角色、技能、物品、统率路线、腐化原物品和翻页只显示中文。
3. 保留并加强英文搜索回归：输入英文角色名仍返回正确中文卡片。
4. 遍历 19 份攻略的所有用户可见字段，检测未批准的拉丁字母残留。
5. 渲染全部 19 个角色路由，检测可见文本与图片替代文本；只允许精确的官方专名清单。
6. 文档和 HTML 元数据测试阻止重新引入中英并列的产品描述。

### 完整验收

- 运行全部单元测试、类型检查、生产构建和 GitHub Pages 子路径校验。
- 校验 221 个本地图标仍与清单一致。
- 在 320 像素手机宽度和桌面宽度检查首页与至少一份长攻略。
- 实测中文搜索、英文搜索、DLC 筛选、角色跳转和章节导航。
- 检查浏览器控制台、断图和横向溢出。

## 发布

- 修改在本地 `main` 分支完成并通过代码复核后推送到公开仓库。
- 等待 GitHub Pages 工作流成功完成。
- 验证公开网址返回成功，并在真实浏览器中确认全中文页面已生效。

## 非目标

- 不删除内部英文名称或资源来源。
- 不改变构筑结论、推荐数量或角色强度判断。
- 不新增语言切换器。
- 不改变站点视觉主题、信息架构或章节数量。
- 不把现有角色搜索扩展成全物品或全技能搜索。
